# Full-Stack E-Commerce Clothing Store

A scalable full-stack e-commerce web application engineered with modern JavaScript frameworks, featuring dynamic product schema modeling, guest checkout flows, an interactive admin dashboard, and robust backend routing.

##  Tech Stack

* **Frontend:** React, Next.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database & ODM:** MongoDB, Mongoose
* **Deployment:** Vercel (Frontend & Admin), Render (Backend API)

##  Features

* **Dynamic Product Catalog:** Browse inventory seamlessly with real-time state management and data fetching.
* **Administrative Dashboard:** Custom admin panel to manage product creation, inventory tracking, and order updates.
* **Secure REST API:** Built with Express.js to handle data routing, middleware authentication logic, and database operations.
* **Cloud Infrastructure:** Fully decoupled architecture with production deployments configured on Vercel and Render.

##  Project Structure

* `Clothing-Store-Frontend/` - Client-facing user interface (Next.js/React)
* `Admin-Frontend/` - Administrative management dashboard
* `Backend/` - Express.js REST API server and MongoDB schemas
